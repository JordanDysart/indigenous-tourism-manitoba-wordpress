# Audit Report: Prairie Berry — Marketing & Conversion

**Page URL:** `https://indigenoustourismmanitoba.ca/operator/prairie-berry/`  
**Audit Concern:** `marketing`  
**Date Audited:** `2026-08-30`  
**Conversion Readiness:** `Good (Strong Culinary Agritourism Appeal; Direct Dinner CTAs Recommended)`  

---

## 1. Executive Summary
The Prairie Berry profile presents an enticing Indigenous-owned agritourism destination celebrated for farm-to-table dinners and fresh berry harvesting along the Red River in Glenlea. Conversion can be significantly increased by deploying high-intent culinary action buttons, adding experience badges, and publishing rich search/social graph metadata.

---

## 2. Detailed Findings

| # | Focus Area | Current State | Identified Gap / Opportunity | Recommended Solution |
|---|---|---|---|---|
| 1 | Culinary Booking Funnel | Single generic "Visit Website" button | Food enthusiasts seeking seasonal farm dinner tickets or berry picking need immediate booking channels. | Implement prominent dual CTAs: *"Book Farm Dinner Tickets"* & *"Plan Berry Picking Visit"*. |
| 2 | Culinary Experience Badges | Mentioned in paragraph copy | Visual badges (Farm-to-Table Dinners, Fresh Berry Picking, Red River Dining, Artisan Baking) quickly highlight key offerings. | Add a "Farm Highlights" badge ribbon to the sidebar overview. |
| 3 | Seasonal Ticket Announcements | Static narrative | Farm dinners sell out quickly each season; adding an email or ticket release notice encourages signups. | Add a "Seasonal Dinner Release Alerts" callout. |
| 4 | SEO & Search Snippet | `<meta name="description">` missing | Search engines lack a rich description for this farm-to-table destination. | Add a targeted meta description (e.g. "Experience farm-to-table culinary dinners, artisan baking, and fresh berry picking with Prairie Berry along the Red River in Glenlea, Manitoba."). |
| 5 | Social Share Previews | Open Graph / Twitter cards missing | Shared links render generic social preview cards without imagery. | Implement standard `og:title`, `og:description`, and `og:image`. |

---

## 3. Checklist Verification

- [x] **Culinary Value Proposition:** Clear, mouth-watering presentation of seasonal dining and farm experiences.
- [x] **Direct Outbound CTA:** Working link to `prairie-berry.com`.
- [ ] **High-Intent Dining Action Buttons:** Lacks direct "Book Farm Dinner" CTAs.
- [ ] **Search Engine Metadata:** Meta description is missing.
- [ ] **Social Media Meta Tags:** Open Graph tags are missing.

---

## 4. Prioritized Action Plan

### 🔴 High Priority / Immediate Fixes
1. **Implement Meta Description & OG Tags:** Add targeted 155-character description and culinary Open Graph tags to `<head>`.

### 🟡 Medium Priority / Improvements
1. **Deploy Farm Dining Action Buttons:** Add *"Book Farm Dinner Tickets"* and *"Plan Berry Picking Visit"* buttons to the operator overview sidebar.
2. **Display Culinary Experience Badges:** Add visual badges for Farm-to-Table Dinners, Berry Picking, and Riverside Dining.

### 🟢 Low Priority / Polish & Recommendations
1. **Highlight Chef Collaborations:** Mention visiting guest chefs or seasonal Indigenous culinary menus.
