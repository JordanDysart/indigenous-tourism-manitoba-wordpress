# Audit Report: Events — Marketing & Conversion

**Page URL:** `https://indigenoustourismmanitoba.ca/events/`  
**Audit Concern:** `marketing`  
**Date Audited:** `2026-08-30`  
**Conversion Readiness:** `Poor (Missing Host CTAs, Event Submission & SEO)`  

---

## 1. Executive Summary
While the Events page features an interactive 3common calendar widget for discovering dates, it currently misses major marketing and conversion opportunities. The host page contains no on-page headlines, introductory value propositions, event submission prompts for local operators, or newsletter lead magnets. Furthermore, the page lacks organic search `<meta name="description">` and social Open Graph tags.

---

## 2. Detailed Findings

| # | Focus Area | Current State | Identified Gap / Opportunity | Recommended Solution |
|---|---|---|---|---|
| 1 | Operator Event Submission CTA | No submission mechanism on page | First Nations, Métis communities, and operators cannot find where to submit cultural events to the calendar. | Add an "Are You Hosting an Event? [Submit Your Event](/contact-us/)" CTA block above/below the calendar. |
| 2 | Value Proposition & Heading | Page jumps immediately into raw iframe | Misses search ranking opportunity and lacks context on seasonal Manitoba celebrations. | Add `<h1>Indigenous Events & Cultural Gatherings</h1>` with a 2-sentence intro. |
| 3 | Newsletter Lead Capture | No event alert subscription option | Visitors seeking seasonal events leave without a capture mechanism. | Embed a "Get Monthly Indigenous Event Updates" email newsletter signup form. |
| 4 | SEO & Search Snippet | `<meta name="description">` missing | Search engines produce blank or unstructured SERP snippets. | Add a targeted meta description (e.g. "Discover upcoming Indigenous events, Pow Wows, cultural festivals, and community gatherings across Manitoba."). |
| 5 | Social Share Previews | Open Graph / Twitter cards missing | Social shares lack branded graphics and descriptions. | Implement standard `og:title`, `og:description`, and `og:image`. |

---

## 3. Checklist Verification

- [ ] **On-Page Value Proposition:** No host text introducing the event calendar.
- [ ] **Search Engine Metadata:** Meta description is missing.
- [ ] **Social Media Meta Tags:** Open Graph tags are missing.
- [ ] **Event Organizer Submission Funnel:** No event submission button or form exists.
- [ ] **Audience Lead Magnet:** No newsletter or event alert capture.

---

## 4. Prioritized Action Plan

### 🔴 High Priority / Immediate Fixes
1. **Add Event Submission CTA Banner:** Insert an event submission prompt for community organizers and tourism members.
2. **Implement Meta Description & OG Tags:** Add targeted 155-character description and Open Graph tags to `<head>`.
3. **Add Primary Page Headline:** Insert `<h1>Indigenous Events in Manitoba</h1>` above the calendar.

### 🟡 Medium Priority / Improvements
1. **Newsletter Event Alerts:** Add a Constant Contact newsletter signup block for upcoming festival announcements.

### 🟢 Low Priority / Polish & Recommendations
1. **Annual Major Festival Spotlights:** Feature permanent promo cards for major annual events like Manito Ahbee Festival.
