# Audit Report: Feast Cafe Bistro — Marketing & Conversion

**Page URL:** `https://indigenoustourismmanitoba.ca/operator/feast-cafe-bistro/`  
**Audit Concern:** `marketing`  
**Date Audited:** `2026-08-30`  
**Conversion Readiness:** `Good (High Brand Equity; Actionable Dining CTAs Needed)`  

---

## 1. Executive Summary
Feast Cafe Bistro holds high brand recognition as one of Canada's premier Indigenous culinary destinations, led by Peguis First Nation Chef Christa Bruneau-Guenther. While the profile effectively captures the spirit of modern Indigenous comfort food, conversion rates can be substantially elevated by adding high-intent dining CTAs ("View Menu", "Reserve Table"), promoting catering/group dining, and configuring search and social graph meta tags.

---

## 2. Detailed Findings

| # | Focus Area | Current State | Identified Gap / Opportunity | Recommended Solution |
|---|---|---|---|---|
| 1 | Culinary Conversion Funnel | Single generic "Visit Website" button | Food tourists seek immediate access to menus, reservations, and takeout ordering. | Implement prominent dual CTAs: *"View Dining Menu"* & *"Reserve a Table"*. |
| 2 | Media & Chef Recognition | Text narrative highlights Chef Christa | Adding national culinary accolades (e.g. Food Network Canada guest judge, national Indigenous culinary pioneer) builds immediate authority. | Add a "Featured In / Accolades" trust badge callout. |
| 3 | Group Dining & Catering | Mentioned briefly in body text | Tour groups, corporate delegations, and event planners need clear group booking channels. | Add a dedicated *"Group Bookings & Catering"* inquiry link. |
| 4 | SEO & Search Snippet | `<meta name="description">` missing | Search engines lack a rich description of Winnipeg's leading modern Indigenous restaurant. | Add a targeted meta description (e.g. "Discover modern Indigenous comfort food at Feast Cafe Bistro in Winnipeg. Experience bannock pizzas, bison burgers, and dishes crafted by Chef Christa Bruneau-Guenther."). |
| 5 | Social Share Previews | Open Graph / Twitter cards missing | Shared links render generic social preview cards without imagery. | Implement standard `og:title`, `og:description`, and `og:image`. |

---

## 3. Checklist Verification

- [x] **Culinary Value Proposition:** Enticing presentation of modern Indigenous cuisine.
- [x] **Direct Outbound CTA:** Link to operator website present.
- [ ] **High-Intent Dining CTAs:** Lacks direct "View Menu" or "Reservations" action buttons.
- [ ] **Search Engine Metadata:** Meta description is missing.
- [ ] **Social Media Meta Tags:** Open Graph tags are missing.

---

## 4. Prioritized Action Plan

### 🔴 High Priority / Immediate Fixes
1. **Implement Meta Description & OG Tags:** Add targeted 155-character description and culinary Open Graph tags to `<head>`.
2. **Resolve Outbound Protocol / SSL:** Ensure outbound links route cleanly to the operator's active domain.

### 🟡 Medium Priority / Improvements
1. **Deploy Dining Action Buttons:** Add *"View Menu"* and *"Reserve Table"* buttons to the operator overview sidebar.
2. **Display Operating Hours:** Add a concise schedule of breakfast/lunch/dinner service.

### 🟢 Low Priority / Polish & Recommendations
1. **Signature Dish Callout:** Highlight top visitor favorites (e.g., "Bison Bannock Burger", "Manitoba Pickerel Sliders", "Wild Rice Pudding").
