# Audit Report: Reconciliation — Marketing & Conversion

**Page URL:** `https://indigenoustourismmanitoba.ca/reconciliation/`  
**Audit Concern:** `marketing`  
**Date Audited:** `2026-08-29`  
**Conversion Readiness:** `Moderate (Missing Next Steps / CTAs)`  

---

## 1. Executive Summary
The Reconciliation page conveys a compelling message of cultural authenticity, truth-telling, and educational tourism. It features four relevant operator experiences (including the National Indigenous Residential School Museum). However, the page suffers from an abrupt exit without inline Call-to-Action buttons to channel visitor interest into booking authentic experiences, exploring the operator directory, or accessing educational guides. SEO `<meta name="description">` and social share tags are also missing.

---

## 2. Detailed Findings

| # | Focus Area | Current State | Identified Gap / Opportunity | Recommended Solution |
|---|---|---|---|---|
| 1 | Page Exit / Conversion CTA | Conclusion of "Grounded in Cultural Authenticity" | Page drops directly into the footer without next steps or conversion prompts. | Add a dual conversion CTA banner: "Explore Authentic Experiences" (`/operators/`) and "View Experience Map" (`/experience-map/`). |
| 2 | Directory Linkage | 4 featured operator cards | No button below the featured grid to view the full directory of cultural operators. | Add an "Explore All Cultural Experiences" button beneath the 4-card grid. |
| 3 | SEO & Search Snippet | `<meta name="description">` missing | Search engines display unstructured text snippets. | Add an impactful meta description (e.g. "Discover how Indigenous Tourism Manitoba advances reconciliation through authentic cultural tourism, community partnerships, and education."). |
| 4 | Social Share Previews | Open Graph / Twitter cards missing | Social shares lack branded preview cards and image thumbnails. | Implement `og:title`, `og:description`, and `og:image`. |
| 5 | Educational Engagement | Solely narrative text | Visitors interested in educational reconciliation resources lack download links. | Add downloadable educational PDFs or links to the TRC Call to Action 92 for business. |

---

## 3. Checklist Verification

- [x] **Value Proposition Clarity:** Strong narrative connecting tourism to education and reconciliation.
- [ ] **Search Engine Metadata:** Meta description is missing.
- [ ] **Social Media Meta Tags:** Open Graph tags are missing.
- [ ] **Actionable CTAs:** No inline CTA buttons exist within the body content.
- [x] **Cultural Authenticity:** Authentic operator spotlights demonstrate tangible community impact.

---

## 4. Prioritized Action Plan

### 🔴 High Priority / Immediate Fixes
1. **Add Bottom Action Banner:** Insert an "Explore Authentic Experiences" CTA banner before the footer.
2. **Implement Meta Description & OG Tags:** Add tailored search description and social sharing metadata to `<head>`.
